A name that fits your profile

Use a single-line style for a display name and a framed style for a bio. ASCII lettering works best in a space that preserves line breaks and uses a monospace font.

Does this change my username?

No. Copy the result into a display-name or bio field. Username fields often accept only ordinary letters, numbers and a few symbols.

Will every app show the same result?

Some apps limit symbols or line breaks, and fonts vary by device. Preview the pasted result before saving. Simple frames are a useful fallback.

Can I use Persian names?

Yes. Persian names retain their connected letters inside decorative frames. ASCII block letters are available for Latin letters and numbers.
