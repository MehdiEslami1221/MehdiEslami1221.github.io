Pick a style that travels well
Use compact lettering for a display name, frames for a bio and ASCII art where spaces and line breaks are preserved. These styles are copyable characters, so the result travels with the text.


Which English styles are available?
Gothic and bold Gothic, calligraphic script, italic, double-struck, sans serif, monospace, circles, squares, small capitals and text effects. Combine them with a frame or emoji.


How do Persian styles work?
Persian options include short and long stretches, classic presentation forms, decorative marks and frames. Joining and half-spaces are respected; English letter styles leave Persian letters in place.


Can I paste these into a username?
Display names and bios usually allow more characters than username fields. Some apps restrict symbols, fonts or line breaks. Preview before saving; the original style is always available.


Where are favorites saved?
Favorite style choices stay in this browser. Your typed name is not stored with them. If browser storage is unavailable, favorites still work until this page is closed.
